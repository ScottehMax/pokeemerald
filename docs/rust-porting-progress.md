# Rust porting progress

Progress is measured by C objects replaced with Rust objects while the ROM remains buildable.

| C source | Rust source | Status | Tests | Validation | Risks/notes |
| --- | --- | --- | --- | --- | --- |
| src/math_util.c | rust/src/math_util.rs | tested | Rust host unit tests cover all nine exported functions, zero-divisor guarded paths, signed truncation, shift variants, and wide intermediates. | `docker compose run --rm builder sh -lc 'export PATH=/usr/local/cargo/bin:$PATH; cd rust && cargo test'`; `docker compose run --rm builder`; `arm-none-eabi-nm` confirmed MathUtil exports in `build/emerald/src/math_util.o` and `pokeemerald.elf`. | Pure arithmetic port; inverse functions intentionally preserve C divide-by-zero precondition. Rust ROM code calls agbcc/libgcc helper symbols for signed division/multiplication to avoid unsupported `__aeabi_*` helpers and panic paths. |
| src/random.c | rust/src/random.rs | tested | Rust host unit tests cover both RNG streams, seed behavior, wrapping LCG output, exported globals, and stream independence. | `docker compose run --rm builder sh -lc 'export PATH=/usr/local/cargo/bin:$PATH; cd rust && cargo test'`; `docker compose run --rm builder`; `arm-none-eabi-nm` confirmed RNG exports and globals in `build/emerald/src/random.o` and `pokeemerald.elf`. | First exported mutable-global port; Rust globals use `common_data`, private EWRAM state keeps the original 8-byte footprint, and `SeedRng` preserves the reset write with volatile access. |
| src/heal_location.c | rust/src/heal_location.rs | tested | Rust host unit tests cover known map lookup, duplicate-map first match, unknown map, null returns for invalid indices, returned struct fields, and C object stride/field offsets. | `docker compose run --rm builder sh -lc 'export PATH=/usr/local/cargo/bin:$PATH; cd rust && cargo test'`; `docker compose run --rm builder`; `arm-none-eabi-nm` confirmed heal-location exports in `build/emerald/src/heal_location.o` and `pokeemerald.elf`; `arm-none-eabi-size -A` confirmed 176-byte `.rodata` table. | Data-backed table port; map constants are copied as numeric group/num encodings from generated C headers. |
| src/blit.c | rust/src/blit.rs | tested | Rust host unit tests cover bitmap layout/dimension packing, 4bpp/8bpp tiled offsets, fill clipping, keyed and unkeyed 4bpp blits, 4bpp-to-8bpp palette/key behavior, and 8bpp fill clipping. | `docker compose run --rm builder sh -lc 'export PATH=/usr/local/cargo/bin:$PATH; cd rust && cargo test'`; `docker compose run --rm builder`; `arm-none-eabi-nm` confirmed blit exports in `build/emerald/src/blit.o` and `pokeemerald.elf`. | Pure buffer-transform port from worker slice; no globals, but pointer arithmetic and packed bitmap layout are high-risk. |
| src/dynamic_placeholder_text_util.c | rust/src/dynamic_placeholder_text_util.rs | tested | Rust host unit tests cover reset, set/get bounds handling, literal expansion, placeholder replacement, null placeholder skipping, and final EOS writes. | `docker compose run --rm builder sh -lc 'export PATH=/usr/local/cargo/bin:$PATH; cd rust && cargo test'`; `docker compose run --rm builder`; `arm-none-eabi-nm` confirmed dynamic-placeholder exports in `build/emerald/src/dynamic_placeholder_text_util.o` and `pokeemerald.elf`; `arm-none-eabi-size -A` confirmed the 32-byte `ewram_data` placeholder table. | Stateful text expansion port; private placeholder pointer table uses `ewram_data`, and ROM code delegates placeholder copies to C `StringCopy`. |
| src/play_time.c | rust/src/play_time.rs | tested | Rust host unit tests cover reset, start clamping above max hours, stopped no-op, vblank-to-second rollover, minute/hour rollover, minute-only rollover, and maxed-out no-op. | `docker compose run --rm builder sh -lc 'export PATH=/usr/local/cargo/bin:$PATH; cd rust && cargo test'`; `docker compose run --rm builder`; `arm-none-eabi-nm` confirmed play-time exports in `build/emerald/src/play_time.o` and `pokeemerald.elf`; `arm-none-eabi-size -A` confirmed the one-byte private BSS state. | Stateful save-block port; Rust mirrors the `SaveBlock2` prefix through `playTimeVBlanks` and keeps the private counter state in normal BSS. |
